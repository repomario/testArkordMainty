# Maintenance Requests

## Capability

Users can report maintenance problems concerning a Facility or Asset so that the problem can be assessed and followed operationally.

## Functional Scope

A Maintenance Request captures its subject Facility or Asset, description, priority, status, and photographs.

## Boundaries and Rules

A request represents reported need rather than proof that maintenance work has been completed. Where work is initiated, its linkage to a Work Order must remain visible.
