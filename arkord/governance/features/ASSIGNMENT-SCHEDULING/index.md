# Technician Assignment and Basic Scheduling

## Capability

Maintenance work can be assigned to Technicians and given a planned date for basic operational scheduling.

## Functional Scope

The capability provides views emphasizing assigned work, priority, today's activities, and overdue work.

## Boundaries and Rules

Assignments identify the Technician responsible for the Work Order. Overdue and today-oriented views derive from the planned date and the Work Order's current state; this is basic scheduling rather than advanced workforce optimization.
