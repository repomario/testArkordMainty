# Operational Notifications

## Capability

Mainty draws users' attention within the application to maintenance events requiring awareness.

## Functional Scope

Notifications cover new assignments, significant Work Order changes, and Critical situations.

## Boundaries and Rules

Notifications are visible within the application and respect the recipient's role and access. Email, push, and other external channels are outside this Feature's established scope.
