# User and Role Management

## Capability

Administrators can create and maintain users and assign the Administrator, Maintenance Manager, or Technician role.

## Functional Scope

User administration includes consultation, modification, role assignment, and activation or deactivation.

## Boundaries and Rules

Deactivation prevents future active use without erasing historical references to the user. User records referenced by past maintenance activity must remain identifiable.
