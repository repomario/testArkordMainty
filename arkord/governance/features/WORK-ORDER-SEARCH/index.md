# Work Order Search and Filtering

## Capability

Users can locate relevant Work Orders without manually reviewing the complete set of records.

## Functional Scope

The capability provides text search and combinable filters for status, priority, Technician, Facility, Asset, and time interval.

## Boundaries and Rules

Multiple selected criteria narrow the result set together. Results reflect only Work Orders the user is authorized to consult.
