# Operational Maintenance Dashboard

## Capability

Administrators and Maintenance Managers receive a consolidated view of current maintenance operations.

## Functional Scope

The dashboard shows indicators for open, in-progress, completed, Critical, and overdue Work Orders.

## Boundaries and Rules

Indicators reflect the underlying Work Order data and current applicable states. The dashboard provides operational visibility rather than advanced analytics.
