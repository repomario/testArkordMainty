# Operational Auditability

## Constraint

For important operations, the system must be able to determine actor, action, and time. Audit information must not be modifiable through normal application functionality.

## Scope and Rationale

This constraint supports accountability and interpretation of significant operational changes. The exact set of operations requiring permanent audit recording remains unresolved and is not established by this Specification.
