# Responsive Web Interface

## Constraint

The interface must adapt to desktop, tablet, and smartphone. Administrative functionality prioritizes desktop use, while Technician workflows prioritize simple and fast mobile use.

## Scope and Rationale

The rule applies across established V1 functionality. Adaptation must preserve access to the information and actions needed for each role rather than merely shrinking a desktop layout.
